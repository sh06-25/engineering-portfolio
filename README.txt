GITHUB PAGES SETUP

1. Extract this ZIP.
2. Upload index.html, style.css, script.js, .nojekyll, and the assets folder to the root of your GitHub repository. Do not upload the ZIP itself.
3. Commit the files.
4. In repository Settings > Pages, select Deploy from a branch, main, and /(root). Save.

To preview on your computer, open index.html after extracting all files.

The website uses plain HTML, CSS, and JavaScript with relative asset paths. It needs no build tools.
